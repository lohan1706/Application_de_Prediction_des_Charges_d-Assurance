Présentation de l’application :

AssurPredict est une application web intelligente conçue pour aider les utilisateurs à anticiper le coût de leurs futures charges d’assurance santé. Grâce à un modèle de machine learning entraîné sur des données réelles, l’application analyse des informations personnelles telles que l’âge, le sexe, le tabagisme, la région ou encore le nombre d’enfants afin d’estimer avec précision le montant probable de l’assurance.

L’objectif principal d’AssurPredict est de simplifier la compréhension des dépenses d’assurance pour tous les profils d’utilisateurs, même ceux qui ne sont pas familiers avec le domaine. L’interface est pensée pour être intuitive : il suffit de remplir un formulaire clair et rapide, puis l’application génère instantanément une prédiction personnalisée, accompagnée d’une visualisation lisible et de conseils éventuels.

Objectif et mode d’utilisation :

L’utilisateur se connecte ou se crée un compte, remplit un formulaire simple, et l’application génère instantanément une prédiction personnalisée du coût de son assurance.
